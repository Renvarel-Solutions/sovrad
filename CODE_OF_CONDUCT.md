# Community conduct

Be respectful, clear and constructive. Welcome contributors with different
backgrounds and levels of experience. Discuss code and ideas without personal
attacks, harassment, discrimination, intimidation or publication of private
information.

Maintainers may edit or remove inappropriate contributions and restrict
participation when needed. For conduct concerns, ask maintainers for a private
contact without including personal or confidential details in a public issue.
For security concerns, use the private vulnerability reporting link in SECURITY.md.
