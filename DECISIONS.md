# Decisions

- 2026-11-01: Product name is Sovrad by Renvarel; intended repository is
  Renvarel-Solutions/sovrad. Application source and synthetic examples are public;
  user projects and runtime records remain private.
- Keep the supplied React Flow/Fastify/SQLite stack. Fix and test the starter
  rather than replacing its architecture.
- AI is backend-only, optional, consent-gated and limited to drafting.
  Specification approval and implementation permission remain separate.
- Runner execution and external project import remain disabled until their
  implementation plans, tests and permissions have been separately approved.
- Public creation/push, merges and deployment are outward-facing approval gates.
